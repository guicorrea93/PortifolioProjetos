🎯 Propósito

Objetivo do Projeto

Agrupar municípios brasileiros com características similares para facilitar tomadas de decisão estratégicas

Expansão de Negócios

Identificar municípios com perfil similar para expansão estratégica de varejo, serviços e franquias

Logística & Distribuição

Otimizar rotas e centros de distribuição baseado em agrupamentos geográficos e densidade populacional

Políticas Públicas

Customizar programas governamentais por perfil socioeconômico, melhorando eficiência e impacto

Análise de Mercado

Segmentar mercados regionais para estratégias de marketing, precificação e desenvolvimento de produtos

🔬 Processo

Metodologia

Pipeline completo de Machine Learning aplicado a dados do IBGE

Etapa 1

Coleta de Dados

Extração de dados via APIs do IBGE (SIDRA): população, PIB, área territorial, indicadores sociais e de infraestrutura

Etapa 2

Análise Exploratória

EDA completo: distribuições, correlações, outliers, padrões regionais e estatísticas descritivas

Etapa 3

Pré-processamento

Tratamento de valores ausentes, remoção de outliers extremos, criação de features derivadas e normalização (StandardScaler)

Etapa 4

Determinação de K

Elbow Method, Silhouette Score, Davies-Bouldin Index, Calinski-Harabasz Score para encontrar número ideal de clusters

Etapa 5

Modelagem KMeans + PCA

Treinamento do modelo KMeans e aplicação de PCA para redução de dimensionalidade e visualização

Etapa 6

Análise & Insights

Interpretação dos clusters, nomeação descritiva, identificação de oportunidades e geração de insights acionáveis
